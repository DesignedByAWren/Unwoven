# Unwoven

<img width="4928" height="3264" alt="DSC_5468" src="https://github.com/user-attachments/assets/7909bf8d-48ff-46b5-b37f-3b752a62f368" />


Unwoven is a project that aims to return the power of manufacturing and craft to the end user of the product. It encourages you to take an active part in the making of a stool, reimagined through the lens of responsible material use within a circular economy.

You are provided with a set of instructions and patterns for building a mould that will allow you to create a stool from recycled textiles, with a particular focus on cotton and denim.

This stool is a purposefully transient object. It will wear and break down with time and exposure to the elements, but it’s constituent materials remain strong, allowing it be destroyed and rebuilt again.

This project can be completed with mostly simple tools and store-bought materials, but a level of experience with power tools and DIY is important to guarantee success and safety. 

From start to finish, the project is expected to take 2-4 weeks.
